# Licensing and redistribution boundaries

The maintainer selected MIT for original Model Agrologistic code, documentation,
manuscript text and project-authored figures, to the extent contributors hold
the rights. See LICENSE. Historical releases and their hashes are unchanged.

This is not a blanket relicensing of research inputs or dependencies.

| Material | Applicable boundary |
|:--|:--|
| Original project contributions and original audit metadata | MIT; underlying data rights remain applicable |
| OpenStreetMap/Geofabrik inputs and derived road databases | Preserve attribution and applicable ODbL obligations |
| Artur/silodss upstream code and benchmark assets | Preserve upstream notices and asset-specific terms; the upstream repository currently carries GPLv3, not MIT |
| Registry and externally supplied Excel inputs | No inferred redistribution permission from possession or public accessibility |
| Quarto SBC adapter and historical SBC style | Preserve the vendored license and separate style notices |
| Gurobi and other dependencies | Their own licenses; credentials are never distributable artifacts |

The software license does not authorize publication of the entire data tree.
Review provenance and redistribution terms per input. An original implementation
of a published formulation does not establish permission to relicense copied
upstream code. Any copied/adapted GPL-covered implementation requires its
applicable terms or separate rightsholder permission. This document is not
completed legal clearance and does not provide that permission.
