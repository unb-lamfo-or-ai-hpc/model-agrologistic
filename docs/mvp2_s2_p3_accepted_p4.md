1. Fresh raw-source/runtime and exact h300 input/dimension checks before a claim;
   fresh running allocation/account/UID/node and native license in the allocation.
2. One-shot submission intent before sbatch; unknown acknowledgement consumes the
   slot. Dedicated new claim, existing start collection-only, no automatic retry.
3. Cold numeric-step worker, same actual affinity pool/topology/native-library
   environment across arms. Record actual allocated CPUs and shared-node effects.
   Kernel isolation remains a site dependency under the academic profile.
4. Monotonic phase-aware900/1800/900/300s deadlines, remaining-block headroom,
   exact-step TERM/KILL and local reap. Only normally closed, intact native
   complete/time-memory-censored products may advance to a distinct planned arm;
   unknown effects, failed cleanup or source/runtime/input drift stop the block.
5. Bound sparse export volume **before** large serialization/transfer. Existing
   partial collector has a256MiB envelope; miniature success does not qualify the
   h300 volume. Streaming/bounded handling must preserve originals on overflow,
   not silently truncate or raise an unreviewed limit. Validate actual partial
   incumbents/residuals/priority degradation independently, not acceptance flags.
6. Qualify scope-specific resources: native Runtime/MaxMemUsed, root high-water
   RSS/CPU, sampled live-tree observations with error/gap/coverage and scheduler
   accounting. Cgroup-v1 unavailability is null/error, not zero or v2 proof.
   Never use a sampled live-tree CPU counter as lifetime CPU or sum independent peaks.
7. Immutable terminal/forensic collection with exact parent/known-step accounting,
   sealed products and external anchors. Interrupted blocks retain original
   attempted prefixes and explicit unrun arms; no full-grid success marker.
8. Complete pinned Bash wrapper/start/status/wait/collect/runbook, negative tests,
   source-closure checks and exact-head Linux CI before Ready. Only then request
   separate merge authorization and provide human NPAD CLI. No CLI now.
